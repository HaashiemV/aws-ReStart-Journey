Rusty Spoon | Nambi Restaurant Website

A static restaurant website developed to establish an online presence for Nambi Restaurant, showcasing the restaurant through a dedicated web experience.

Live Website: https://rustyspoon-nambi.s3-website-eu-west-1.amazonaws.com/

Project Overview

Rusty Spoon is a web development project focused on creating a simple, accessible restaurant website.

The project demonstrates how static website technologies can be hosted using Amazon S3.

Technologies Used

Technology| Purpose
HTML| Website structure
CSS| Styling and layout
JavaScript| Front-end functionality
Amazon S3| Static website hosting

AWS Architecture

The website uses Amazon S3 to store and serve its static website files.

1. User
↓
2. Amazon S3 – Hosts the website files.
↓
3. HTML, CSS and JavaScript – Render the website in the browser.
