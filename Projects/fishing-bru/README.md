Fishing Bru | Cape Town Fishing Companion

A hobby project exploring a digital fishing companion for shore anglers in Cape Town, South Africa.

Project Type: Personal Development Project
Project Status: In Progress

Project Overview

Fishing Bru is designed to help shore anglers make more informed fishing decisions by combining fishing conditions, location information, fishing knowledge and personal catch records.

The concept focuses on making useful fishing information accessible through a simple, mobile-friendly experience.

Planned Features

1. Fishing Spot Checker

A tool designed to help anglers assess potential fishing locations using:

- Swell conditions.
- Wind conditions.
- Target fish species.
- Angler experience level.
- Location-specific considerations.

2. Cape Town Fishing Locations

The project considers popular shore fishing areas, including:

- Strand.
- Gordon's Bay.
- Muizenberg.
- Kalk Bay.
- Bloubergstrand.
- Hout Bay.
- Kommetjie.

3. Fishing Regulations Guide

A dedicated section to help users understand relevant fishing regulations and responsible fishing practices.

4. Personal Catch Log

A proposed catch-recording feature with fields for:

- Fish species.
- Fish length.
- Fishing location.
- Bait used.
- Weather notes.
- Whether the fish was released.

5. Community Features

Future plans include allowing anglers to share fishing experiences and catches.

Technologies and Concepts

- HTML – Application structure.
- CSS – Styling and responsive layout.
- JavaScript – Front-end functionality.
- Browser Local Storage – Potential local data persistence.
- Map links – Location discovery.
- Fishing condition assessment – Supporting fishing decisions.

Potential Business Model

The concept also explores a possible free and premium subscription model.

The free offering would provide core fishing information, while premium features could be considered as the project develops.

This remains a proposed business model, not an implemented subscription system.

Future Improvements

- Live weather integration.
- Tide and swell information.
- More detailed fishing condition assessments.
- Improved location mapping.
- Catch history and statistics.
- Community functionality.
- Verified fishing regulations and updates.

Project Status

In Progress – Hobby Project

Fishing Bru is an ongoing concept and development project. Features described as future improvements are not yet represented as completed functionality.
